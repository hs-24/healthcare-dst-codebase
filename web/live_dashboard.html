ML Forecasting Model

AR(2) Autoregressive Model
Live agent uses AR(2) OLS (activates after 5 days). Warm-up: ETS α=0.3. Offline comparison uses ARIMA(1,1,1).
Run py run_pilot.py to load ARIMA comparison data.
Why AR(2) live, ARIMA offline?
  • AR(2) runs in O(1) per tick — fits the agentic loop where every SKU is evaluated every simulated day. Needs only last 2 demand observations.
  • ARIMA(1,1,1) requires a full history batch fit — used offline for accuracy benchmarking, not viable for real-time per-SKU decisions.
